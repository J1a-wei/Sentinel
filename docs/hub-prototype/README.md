# Sentinel Hub UI 原型

基于 [需求与分期](../requirements.md) 和 [数据库设计](../database.md) 制作的中文交互原型。页面使用虚构数据，展示一期操作流程；不连接真实 Hub、Scout、数据库或消息服务。

## 打开方式

在线私有预览：[Sentinel Hub](https://sentinel-hub-prototype-k4m8.dapper-flute-4614.chatgpt.site)。通过 Sites 发布，保持仅所有者可访问。

直接用浏览器打开 [dist/index.html](dist/index.html)，或在仓库根目录运行：

```sh
python3 -m http.server 8173 --bind 127.0.0.1 --directory docs/hub-prototype/dist
```

随后访问 `http://127.0.0.1:8173/`。这是静态页面，无需安装前端依赖或构建。

静态效果图：[安全总览预览](preview.png)。

## 页面与交互

| 页面 | 可以体验的内容 |
| --- | --- |
| 安全总览 | 当前资产、在线率、风险、采集覆盖；管理组筛选、演示趋势范围、风险主机入口、报告导出 |
| 主机资产 | 1,248 台虚构主机；名称/IP 搜索、状态/风险筛选、多个标签交集、排序、分页和批量选择 |
| 主机详情 | 宿主机指标、资产/安装/实例身份、软件包、端口、基线、任务六个标签页 |
| 端口清单 | TCP 监听/UDP 绑定区分、`127.0.0.0/8` 与 `::1` 隐藏、独立 Docker 发布映射 |
| 漏洞风险 | 技术状态与人工处置独立；证据抽屉、确认/接受风险、只读复查 |
| 配置基线 | SSH/PAM 规则、通过/不通过/未知统计、上下文与磁盘/运行状态说明 |
| 诊断任务 | 创建有类型的只读任务、限制超时/资源预算、模拟执行阶段、取消待确认、导出摘要 |
| 采集策略 | 按管理组查看适用策略、继承关系、填写理由并创建演示修订 |
| Scout 升级 | 发布兼容信息、灰度目标、跳过未决升级、逐阶段模拟交接与提交 |
| 日志调查 | 后续能力占位，不显示虚构的已接入日志或假查询结果 |

建议评审路径：总览 → 主机详情 → 端口过滤/风险证据 → 发起只读检查 → 任务详情 → 模拟下一阶段。另一条路径为创建灰度批次 → 逐次推进预检、候选启动、交接、观察、提交。

## 数据与行为边界

- 数据由固定种子生成，名称、地址、任务、发布版本与漏洞记录均为演示。`DEMO-CVE-*` 不是真实漏洞编号，软件包版本关系不作为修复依据。
- 数量、关联和当前风险由同一数据集派生。风险接受不改变技术状态，也不减少仍存在的风险计数。
- 实时指标与软件包采集时效分别表达。失败尝试保留旧清单及其时间；过期或缺测指标显示“—”，不补零。
- 分钟历史保留 7 天、小时历史保留 90 天。图表是预设演示序列，未实现真实聚合或历史查询。
- 基线页面明确现有密码强度未验证，不读取密码、密码散列或配置原文。
- 任务只在浏览器内模拟；取消请求不代表已停止，升级 unknown 不能直接重复派发。演示升级提交后才更新示例资产版本。
- AI 尚未接入；恶意文件检测属于第二期。原型不执行扫描、系统修改或自动处置。
- 编辑、任务和处置保存在当前页内存中，刷新恢复初始状态。前端筛选不是正式授权控制；正式权限校验由后端实施。

## 文件

```text
hub-prototype/
├── .openai/hosting.json   # 私有预览站点标识，不含凭证
├── README.md
└── dist/
    ├── index.html        # 应用外壳与入口
    ├── styles.css        # 视觉系统和响应式布局
    ├── app.js            # 路由、页面和浏览器内交互
    ├── data.js           # 关联一致的虚构数据
    └── favicon.svg       # Sentinel 标识
```

使用原生 HTML、CSS 与 JavaScript。此选择仅用于可直接打开的 UI 原型，不锁定正式前端框架，也不改变 Hub/Scout 的 Rust 技术栈。无外部字体、图片或脚本依赖。

## 验证

已在独立 Chrome 会话通过 17 项业务交互检查，另验证手机菜单关闭与详情标签键盘切换。9 个主要视图分别在 1440px 桌面和 390px 手机宽度检查，共 18 个视口场景无页面横向溢出、无浏览器脚本异常；直接打开本地 HTML 也可运行。验证不代表后端权限、消息一致性或真实主机升级已经实现。
